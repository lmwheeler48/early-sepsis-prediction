## 📊 Exploratory Data Analysis (EDA)

This directory contains the processed outputs and key figures generated from our **EDA and data-cleaning pipeline**.

> ⚠️ **Note:** Due to file-size and privacy restrictions, **not all intermediate outputs and visualizations could be uploaded** here.  
> The files available in this folder are representative outputs **generated directly from the notebook `EDA_Data_Cleaning.ipynb`**, which includes:
> - Data preprocessing (missing-value handling, winsorization, scaling)
> - Exploratory summaries and feature statistics
> - Correlation heatmaps and Cohen’s *d* analysis
> - Aggregated patient-level metrics for modeling inputs

The complete EDA workflow prepares the cleaned, standardized dataset used later for model training and evaluation (see `GRU_D_Model.ipynb` for downstream modeling).
